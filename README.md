# itfetter · 开发手记

一个记录个人项目、日常 AI 使用体验和开发踩坑的中文个人博客。当前版本使用样稿演示文章归档、长文阅读、开发笔记、项目和本地写作。

## 本地打开

1. 下载或检出本仓库。Windows 上使用已有的 Python 3，无需安装项目依赖。
2. 双击 `start-preview.bat`，打开 [本地预览](http://127.0.0.1:8081/)。关闭启动窗口即可停止服务。
3. 其他系统可在项目目录运行 `python3 -m http.server 8081 --bind 127.0.0.1`，然后打开同一个地址。

首页从置顶文章和最近文章开始。进入「文章」可按主题筛选，也可用 `/` 或 `Ctrl/Cmd+K` 搜索。键盘方向键选择结果，Enter 打开，Esc 退出。

在「写作台」编辑 Markdown 并实时预览。草稿保存在当前浏览器，可导出 `.md` 文件。将文章放进站点时，编辑 `index.html` 中的 `posts` 数据。

## 部署

把根目录的 `index.html` 发布到静态站点的根目录即可。无需构建命令或数据库。发布后检查首页、带 `#post/` 的直达链接和静态页面加载。公开发布前，将原型样稿替换为实际内容。

## 长期规划

先用真实文章验证阅读与写作体验，再根据内容量整理文章源文件和发布流程。主题归档、RSS 和移动端细节随实际写作需求推进。
