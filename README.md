# itfetter · 开发手记

一个记录个人项目、日常 AI 使用体验和开发踩坑的中文个人博客。当前版本使用样稿演示文章归档、长文阅读、开发笔记、项目和本地写作。

## 本地打开

1. 下载或检出本仓库。Windows 上使用已有的 Python 3，无需安装项目依赖。
2. 双击 `start-preview.bat`，打开 [本地预览](http://127.0.0.1:8081/)。关闭启动窗口即可停止服务。
3. 其他系统可在项目目录运行 `python3 server.py`，然后打开同一个地址。

首页从置顶文章、最近文章和笔记开始。进入「文章」可按主题筛选，「笔记」可按类别筛选和展开正文，「项目」可查看进度、详情和关联文章。用 `/` 或 `Ctrl/Cmd+K` 搜索这三个栏目，键盘方向键选择结果，Enter 打开，Esc 退出。

在地址栏直接打开 [后台登录](http://127.0.0.1:8081/admin)。使用启动窗口显示的用户名和临时密码，或继续使用已在后台设置的密码。从左边选文章、笔记、项目或站点设置。列表支持搜索和状态筛选，点行内「编辑」打开内容。文章编辑页可保存草稿或直接发布。给已发布文章保存草稿时，列表显示「已发布 · 有草稿」，读者继续看到上一版。需要下架时，可在编辑页点「撤回发布」。

文章编辑器支持连续文档编辑、Markdown 源码和预览。复制截图或图片后可直接粘贴到正文，也可以点击「插入图片」选择文件。「发布设置」里可以上传封面和填写替代文字。支持 PNG、JPEG、WebP、GIF，每张最多 8 MB。草稿图片只有后台登录后可以预览，文章发布后读者即可查看。

文章、草稿、笔记、项目、站点设置、评论、浏览量和点赞保存在 `blog.sqlite3`。新版本首次启动时自动导入已有的 `blog-data.json`，并保留原文件。上传的图片保存在同级的 `uploads/`，正文和封面存储图片地址。

填写标题后，文章修改会在停止输入约一秒后自动保存为草稿。底部操作栏显示保存和发布结果，编辑位置与模式会保留。发布文章、发布更新、撤回和删除需要确认。文档编辑时用 `Ctrl+Z` 撤销，用 `Ctrl+Shift+Z` 或 `Ctrl+Y` 重做。输入、粘贴和块操作使用同一份编辑记录，历史记录保留在当前编辑会话中。

## 部署

GitHub Actions 构建并检验 Linux 镜像，发布到 `ghcr.io/itfetter/itfetter-blog-dev-notes`。服务器使用 [Compose 配置](deploy/compose.yaml)，反向代理指向容器配置的回环端口。

首次部署时，按 Compose 配置准备可写的数据目录，并通过只读挂载提供至少 16 个字符的初始密码。容器运行用户需要相应的读写权限。生产后台的登录 Cookie 通过 HTTPS 使用。

登录后从「站点设置 → 修改登录密码」填写当前密码并确认新密码。新密码至少 6 位字符，保存后需重新登录。

更新时，在实例目录设置 `BLOG_IMAGE` 为目标 GHCR 镜像摘要，再执行 `docker compose pull` 和 `docker compose up -d`。备份时可暂停容器后复制整个数据挂载目录，包含 `blog.sqlite3`、`uploads/` 和旧 JSON。反向代理与域名由服务器单独配置，代理的请求体限制也会影响可上传的图片大小。

### 静态导出

在后台「站点设置」导出公开 `content.js`，将它与 `index.html`、`styles.css`、`markdown.js` 和 `assets/` 一起发布到静态站点根目录。导出的内容仅含已发布条目。发布后检查首页和 `#post/` 直达链接。本地管理服务仅监听回环地址。

首页文章列表、归档和正文目录显示评论总数，计入回复。正文讨论区支持昵称留言、行内代码和回复。评论由同源 Python 接口写入 SQLite。静态导出的评论数为导出时的快照。单独使用静态导出的 `content.js` 时，需将文中引用的已发布图片一并放到静态站点的 `/media/` 路径。

打开文章记录浏览，同一浏览器每篇每天计一次。正文的点赞按钮可以点赞及取消，首页与归档展示总数。实时浏览和点赞需要同源 Python 接口，静态导出显示导出时的总数。

## 长期规划

先用真实文章验证阅读与写作体验，再根据内容量整理文章源文件和发布流程。主题归档、RSS 和移动端细节随实际写作需求推进。
