# itfetter · 开发手记

一个记录个人项目、日常 AI 使用体验和开发踩坑的中文个人博客。当前版本使用样稿演示文章归档、长文阅读、开发笔记、项目和本地写作。

## 本地打开

1. 下载或检出本仓库。Windows 上使用已有的 Python 3，无需安装项目依赖。
2. 双击 `start-preview.bat`，打开 [本地预览](http://127.0.0.1:8081/)。关闭启动窗口即可停止服务。
3. 其他系统可在项目目录运行 `python3 server.py`，然后打开同一个地址。

首页从置顶文章和最近文章开始。进入「文章」可按主题筛选，也可用 `/` 或 `Ctrl/Cmd+K` 搜索。键盘方向键选择结果，Enter 打开，Esc 退出。

在地址栏直接打开 [后台登录](http://127.0.0.1:8081/admin)，使用本地预览账号 `amdin` 和密码 `123456`。从左边选文章、笔记、项目或站点设置。列表支持搜索和状态筛选。选中已有标题可修改，保存为「已发布」后刷新前台即可查看。把状态改为草稿可以撤回。

文章编辑器支持块编辑、Markdown 源码和预览。点击正文块左边的菜单，或在空白块输入 `/`，可以选择标题、列表、引用或代码块。旧浏览器草稿可以在新建文章时带入。保存后的草稿和发布内容都存放在项目目录的 `blog-data.json`，迁移后台时请一并备份该文件。

## 部署

在后台「站点设置」导出公开 `content.js`，将它与 `index.html`、`styles.css`、`markdown.js` 一起发布到静态站点根目录。导出的内容仅含已发布条目。发布后检查首页和 `#post/` 直达链接。本地管理服务仅监听 `127.0.0.1`，默认账号和密码用于本机预览。

## 长期规划

先用真实文章验证阅读与写作体验，再根据内容量整理文章源文件和发布流程。主题归档、RSS 和移动端细节随实际写作需求推进。
